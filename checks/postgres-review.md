## Limits

Physical camera not tested; video stream emulated. Profile/renewal settings remain browser-local. No real payment, refund or subscription billing. JSON fallback remains single-process. PostgreSQL locks one JSONB row for demo writes; normalize to the retained relational models as volume grows. Uploaded bytes stay in DB for the small demo, not a large media catalog. Publicly documented demo passwords require restricted access and replacement before real operation. Earlier review files describe their historical JSON implementation; this report and README describe the current DB path. Public Vercel availability requires a separate deployment smoke test.
